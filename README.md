# MACHI EVENT DROP（イベント情報掲載サイト・雛形）

**データベース不要・JSONだけで運用できる**ミニマム構成のイベント情報掲載サイトです。

## デザインの参照元

- **レイアウト・カード表現**：[SANKOU!](https://sankoudesign.com/)
  白ベース・大胆な余白・画像主体のフラットなカードグリッド、ピル型フィルター、
  ヘッダーの検索バーなど、「探しやすさ」を重視したエディトリアルなレイアウトを参考にしています。
  ※メニュー構成やコンテンツ内容は踏襲せず、あくまでレイアウト表現のみを参考にしています。
- **配色・フォント・ブランドトーン**：[とうじょうRMO](https://tojo-rmo.github.io/lp/)
  深いグリーン（`#2f7a43`）×ゴールド（`#b3923f`）の落ち着いた地域密着型配色と、
  Noto Sans JP + Inter のフォント構成を踏襲し、地域情報サイトとしてのトーンを統一しています。

この2つを掛け合わせ、**「地域のイベント情報を検索する」機能性を担保しながら**、
洗練されたデザインに仕上げています。

---

## 主な機能

- **キーワード検索**：ヘッダーの検索ボックスから、タイトル・住所・カテゴリを横断してリアルタイム検索
- **カテゴリ絞り込み**：ピル型のチップで、カテゴリごとに件数を表示しながら絞り込み
- **お気に入り機能**：カードのハートアイコンでお気に入り登録（ブラウザのlocalStorageに保存）。
  「お気に入り」チップで、お気に入り登録したイベントだけを表示可能
- **詳細モーダル**：カードをクリックすると詳細情報をポップアップ表示（`detail`列はHTML入力に対応）
- メニューバーは持たない、ロゴ＋検索のみのミニマムなヘッダー構成

## 1. ファイル構成

`images/thumbnails/` 以外のファイルは、すべて同じ階層（ルート直下）に配置しています。

```
event-site/
├── index.html    … ページ本体（基本的に編集不要）
├── style.css     … デザイン（配色・余白などのトークンは冒頭 :root に集約）
├── config.js     … ★サイト共通設定（文言・挙動・配色ルールなど）
├── main.js       … 検索／絞り込み／お気に入り／詳細モーダルの制御（基本的に編集不要）
├── events.json   … ★イベントデータ本体（CMS代わり。運用で更新するのはここがメイン）
└── images/
    └── thumbnails/   … イベントのサムネイル画像を置く場所
```

日常的な更新は **`events.json` を差し替えるだけ** で完結するように設計しています。

## 2. イベントデータの更新方法（`events.json`）

配列の中に、イベント1件＝オブジェクト1つとして追加・削除・編集するだけです。

```json
{
  "id": "evt-001",
  "title": "リバーサイド・アートフェスティバル 2026",
  "thumbnail": "sample-art.jpg",
  "category": "アート・デザイン",
  "address": "大阪府大阪市北区中之島公園周辺",
  "url": "https://example.com/events/art-festival",
  "detail": "<p>川沿いの遊歩道と公園一帯を舞台に…</p><h3>見どころ</h3><ul><li>夜間ライトアップ</li></ul>"
}
```

| 項目 | 必須 | 説明 |
|---|---|---|
| `id` | ○ | 一意のID。お気に入り保存のキーにもなるため、他と重複しない文字列にしてください |
| `title` | ○ | イベントタイトル。カード見出し・モーダル見出し・検索対象に使用 |
| `thumbnail` | 任意 | `images/thumbnails/` 内の画像ファイル名。空欄や画像が存在しない場合は、カテゴリ名入りのプレースホルダーが自動表示されます |
| `category` | 任意 | カテゴリ名（自由入力）。新しいカテゴリ名を入れると、フィルターやタグの色も自動で追加されます |
| `address` | 任意 | 開催場所・住所。検索対象にも使用されます |
| `url` | 任意 | 公式サイトのURL。カード上の外部リンクアイコン、モーダル内の「公式サイトを見る」ボタンのリンク先 |
| `detail` | 任意 | カードをクリックした際に表示される詳細説明文。**HTMLタグがそのまま有効になります** |

### `detail` にHTMLを書く場合の注意点

`detail` の中身はエスケープせず、そのままページに埋め込まれます。
`<p>` `<h2>` `<h3>` `<ul>` `<li>` `<b>` `<a>` などが利用可能です。
JSON内で改行・ダブルクォートを使う場合はエスケープ（改行は `\n`、`"` は `\"`）が必要です。

**`detail` は運用者が入力する信頼できるHTMLである前提です**（外部ユーザー入力をそのまま入れる用途には使用しないでください）。

## 3. 検索・絞り込み・お気に入りについて

- **キーワード検索**：ヘッダーの検索ボックスに入力すると、`title` / `address` / `category` を対象に
  リアルタイムで絞り込みます（大文字・小文字を区別しません）。カテゴリ絞り込みと併用可能です。
- **カテゴリチップ**：各チップには該当件数が表示されます。クリックで単一選択の絞り込みです。
- **お気に入り**：カード下部の右側に並ぶハートアイコンをクリックするとお気に入り登録され、
  ブラウザの `localStorage` に保存されます（サーバー保存ではないため、別ブラウザ・別端末とは共有されません）。
  フィルター行末尾の「お気に入り」チップから、登録済みイベントのみを表示できます。

---

## 4. イベント詳細のモーダル表示について

- イベントカード全体をクリック、またはキーボードでフォーカスして Enter / Space を押すと、
  画面中央にモーダルが表示されます。
- 閉じるには、右上の ✕ ボタン、モーダル外側のクリック、または **Escキー** をご利用いただけます。
- カード上の「外部リンクアイコン」やお気に入りの「ハートアイコン」をクリックした場合は、
  モーダルを開かずにそれぞれの動作のみが実行されます。

## 5. サイト共通設定（`config.js`）

サイト名・見出し・ボタン文言・カテゴリごとの色などを一箇所にまとめています。

| 設定キー | 内容 |
|---|---|
| `siteName` / `siteNameSub` | ヘッダー・フッターに表示するサイト名 |
| `catchCopy` / `leadText` | 一覧セクションの見出し（h1）・リード文 |
| `footerText` / `footerLead` | フッターの著作権表記・リード文 |
| `dataSource` | 読み込むJSONファイルのパス（差し替え可） |
| `thumbnailBasePath` / `thumbnailFallbackText` | サムネイル画像フォルダのパス／画像なし時の代替文言 |
| `categoryColorMap` / `categoryColorPalette` | カテゴリごとの色指定・自動割当パレット |
| `showAllCategoryLabel` | 「すべて」チップの文言 |
| `searchPlaceholder` / `searchClearLabel` | 検索ボックスのプレースホルダー・クリアボタンのaria-label |
| `favoritesChipLabel` / `favoriteAddLabel` / `favoriteRemoveLabel` | お気に入り関連の文言 |
| `resultCountSuffix` / `resultCountSearchLabel` | 検索結果件数表示の文言 |
| `officialSiteLabel` / `externalLinkLabel` | 公式サイトリンクの文言・aria-label |
| `itemsPerLoad` / `loadMoreLabel` | 初期表示件数・「もっと見る」ボタン文言（`itemsPerLoad`を0以下にすると全件表示） |
| `emptyStateText` / `loadErrorText` | 該当件数0件時／読み込み失敗時の文言 |
| `detailFallbackText` / `modalCloseLabel` | 詳細未設定時の文言／閉じるボタンのaria-label |

新しいカテゴリを追加したい場合、`config.js` を編集しなくても `events.json` にそのカテゴリ名を書くだけで
フィルターに自動追加され、色も自動で割り当てられます（固定色にしたい場合のみ `categoryColorMap` に追記）。

## 6. デザインの調整（`style.css`）

ファイル冒頭の `:root { ... }` にブランドカラー・角丸・影などをまとめています。

```css
--green: #2f7a43; /* ← メインカラー（アクティブ状態・リンク） */
--gold:  #b3923f; /* ← サブアクセント */
--ink:   #20241f; /* ← 見出し・本文の濃色（SANKOU!同様、モノトーン基調の主色） */
```

### PC表示について

コンテナ幅は `max-width:1200px` に統一し、超ワイドモニターでもカード群が間延びしないよう
3カラム固定（960px以下で2カラム／640px以下で1カラム）にしています。カード自体は枠線・影を持たず、
余白とサムネイルの角丸のみで区切る、SANKOU!のようなフラットな見た目にしています。

## 7. ローカルでの確認方法

`index.html` を直接ブラウザで開く（`file://`）と、ブラウザのセキュリティ制限により
`events.json` の読み込みが失敗する場合があります。必ず簡易HTTPサーバー経由で確認してください。

```bash
# event-site フォルダ内で実行
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## 8. 公開（デプロイ）方法

静的ファイルのみで完結するため、以下のような任意の静的ホスティングにそのままアップロードするだけで公開できます。

- GitHub Pages / Cloudflare Pages / Netlify / Vercel
- Azure Static Web Apps / AWS S3 + CloudFront
- 社内・レンタルサーバーのWebサーバー（Apache/Nginx等）にファイル一式を配置

**データベースやサーバーサイド処理は不要**です。イベント情報の更新は、公開後も
`events.json` をアップロードし直すだけで反映されます。
